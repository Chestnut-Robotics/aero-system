# Aero Hand & Aero UMI

Official project page for the Aero Hand and Aero UMI paired platform from Chestnut Robotics.

**Website:** https://chestnut-robotics.github.io/aero-system/

## Publishing

This is a buildless static website. GitHub Pages serves the repository root on the `main` branch. Updating `index.html` and pushing to `main` updates the site without changing its URL.

The initial project preview uses product images and video already published at https://chestnut.bot/. The assets remain hosted on the company website. No internal reports, engineering files, or private planning documents are included.

## Local preview

Open `index.html` in a browser, or serve the repository with any static file server.

## Scope

This repository contains the project website only. It is not a release of the robot hardware, firmware, SDK, or research data. Additional demonstrations and technical resources will be added here as they become available.
